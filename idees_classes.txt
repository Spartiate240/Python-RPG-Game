KNIGHT
Squire → Knight ─┬─ Spellblade → Runeknight → Archblade
                 ├─ Lord → <Je ne sais pas...> → Praetorian
                 └─ Dark Knight ─┬─ Death Knight → Doom Knight
                    (quête)      └─ Dragon Knight → Dragonlord

WARRIOR
Recruit → Warrior ─┬─ Berserker → Jarl → Warlord
                   └─ Swordsman → Champion → Weapon Master

HOLY
Acolyte → Initiate ─┬─ Cleric → Bishop → Patriarch          (sorts, bénédictions)
                    └─ Inquisitor → Holy Guardian → Paladin (combat)

MAGE
Apprentice → Conjurer → Magician ─┬─ Spelldancer → Archmage
                                  ├─ Geomancer → Elemental Sovereign
                                  └─ Astramancer → Zodiac Sage

SORCERER
Hexer → Sorcerer → Occultist → Warlock → Doomcaller

HUNTER
Hunter → Ranger ─┬─ Trapper → Tracker → Warden           (traque, pièges)
                 └─ Beastcaller → Beastmaster → Master of the Wild

SAMURAI
Ashigaru → Bushi → Samurai → Daimyo → Shogun
                  (branche optionnelle au T3 : Ronin → Kensei → Sword Saint)

NECROMANCER
Reanimator → Necromancer → Necrolord → Lich → Lich King

THIEF
Cutpurse → Thief → Burglar → Master Thief → Thief King

ASSASSIN
Cutthroat → Slayer → Executioner → Assassin → Master Assassin
